One download. Everyone ready.

Install once. Quest together.

01 / DOWNLOAD

Extract the whole ZIP

Close WoW. Download the complete package above, then use Extract All. Keep PlxTogether-Setup.exe, Support, and AddOns together.

02 / INSTALL

Run PlxTogether-Setup.exe

Choose your Forever client folder containing the WoW executable (WowB.exe on the current beta). The standard _classic_beta_ location is filled in by default. If Windows denies access, approve the Windows administrator prompt.

03 / PLAY

Enable your addons

At character selection, enable PlxTogether, Questie, QuestieDB, and any bundled dependencies. Everyone in your Horde party needs version 0.6.0 for live position sharing and quest-chain suggestions.

Prefer to install manually, or use macOS?

Copy every folder inside the package’s AddOns directory into your Forever client’s Interface/AddOns folder. PlxTogether, Questie, and QuestieDB sit beside each other. Do not put the entire friends package inside AddOns. Use Battle.net’s Show in Explorer / Show in Finder to locate the client you actually play.

Try it without a party

Your first two minutes

  1. Type /plx demo to load three simulated players at different levels.
  2. Close the large Details window. The small route tracker stays on your screen.
  3. Click Next step to advance simulated pickups, objectives, and turn-ins.
  4. Type /plx live to return to your character.

Demo quests are fictional. The preview does not change your quests or send party messages.

When your friends join

Follow the shared stops

Form a normal Horde party and meet in the same zone. The planner waits for everyone’s data, favors quests with XP for every member, and shows who needs each task.

/plx opens Details.
/plx hud show restores the tracker.
/plx guide opens the in-game guide.
/plx status checks party readiness.

Numbered live stops and recent party positions appear on the world map. GPS travel time is a straight-line estimate; terrain and combat can change it. Positions are shared only through the current WoW party, and disappear when stale.

Quick fixes

Keep the party moving.

The tracker disappeared.

Type /plx hud show. Drag the small panel to reposition it. Closing Details or pressing Escape does not hide the tracker.

No shared route appears.

Use /plx status. Everyone must have the same addon version, Questie loaded, and fresh data in the same zone. Leave raid groups. Completed or locked quests, unknown XP, and missing local coordinates can limit recommendations.

Why does this include Questie?

Questie supplies the quest database, XP estimates, and map locations. PlxTogether uses that information to compare party members and plan shared stops. Questie is preserved as a separate addon in the package.

Is the Forever beta routing fully verified?

This is a working prototype with automated routing and UI tests. Forever beta XP rules, actual map behavior, and the tracker still need in-game verification. AI integration is not included in this release.
